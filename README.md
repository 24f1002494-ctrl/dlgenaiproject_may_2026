# dlgenaiproject_may_2026
Git repository created for Kaggle project of Deep learning project in May 2026 term

Project Overview

This repository demonstrates how to build a production-quality Retrieval-Augmented Generation (RAG) pipeline for Multiple Choice Question Answering (MCQA). The project is designed to be both an educational resource and a modular machine learning pipeline that can be extended and improved over time.

Rather than focusing only on obtaining a good competition score, this project explains every stage of the pipeline—from building a Knowledge Base to retrieving relevant context, reranking documents, and making final predictions using a zero-shot classifier.

🎯 Objectives
Build a reusable Retrieval-Augmented Generation pipeline.
Understand each component of a modern RAG system.
Evaluate retrieval quality using standard Information Retrieval metrics.
Evaluate prediction quality using MAP@3.
Produce a valid Kaggle competition submission.
