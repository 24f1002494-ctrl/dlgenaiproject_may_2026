# Deep Learning & Generative AI Project - May 2026

## Overview

This repository contains my submission for the Deep Learning & Generative AI assignment (May 2026).

The project focuses on building a Retrieval-Augmented Generation (RAG) pipeline for Multiple Choice Question Answering (MCQA).

The implementation combines:

- Sentence Embeddings
- FAISS Vector Search
- Cross-Encoder Reranking
- Zero-Shot Classification
- Retrieval-Augmented Generation (RAG)
- Experiment Tracking using Weights & Biases

The project is developed incrementally through five milestones.
